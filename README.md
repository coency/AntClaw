# 爬爬蚁（AntClaw）

把**自己账号**的**创作者数据中心**数据一键导出为 **CSV**（含作品封面 ZIP）的 Chrome 扩展，支持 **上一个月 / 上一周** 周期。

面向 **抖音创作者中心** 与 **微信视频号助手**；小红书、哔哩哔哩为占位（提示“暂未接入”）。

> 只读工具：仅在你已登录的官方平台页面上、且由你主动点击时，调用平台自身的数据接口读取统计；低频、不做批量循环、不外发任何数据。

---

## 功能特性

- **两个平台**：抖音、微信视频号（同一弹窗内切换）。
- **两种周期**：上一个月（自然月）、上一周（自然周）。
- **三类导出**：
  - 汇总 CSV（周期内整体指标）
  - 单篇 CSV（逐作品明细）
  - 封面 ZIP（作品封面图打包）
- **抖音单篇全接口直取**：标题 / 时长 / 播放 / 点赞 / 评论 / 分享 / 收藏 / 弹幕 / 完播率 / 5秒完播率 / 2秒跳出率 / 平均播放时长 / 涨粉 / 脱粉 / 粉丝播放占比 / 最大流量来源 / 搜索关键词，**秒出、无需逐个打开作品详情页**。
- **视频号企微指标**：单篇包含 企微链接点击次数 / 人数、添加通讯录次数 / 人数。

## 安装（开发者模式）

1. 获取本仓库源码（`git clone` 或下载 ZIP 解压）。
2. 打开 `chrome://extensions`，右上角开启**开发者模式**。
3. 点「**加载已解压的扩展程序**」，选择本仓库中的扩展目录 **`antclaw`**。
4. 在已登录创作者平台的页面点击扩展图标即可使用。

## 使用方法

1. 先在浏览器登录对应平台：抖音 = `creator.douyin.com`，视频号 = `channels.weixin.qq.com`。
2. 点击扩展图标，选择**平台**与**周期**。
3. 点「**提取数据**」。
4. 提取完成后，点「**下载汇总**」「**下载单篇**」「**下载封面**」分别保存。

## 导出字段

### 微信视频号
- **汇总**：周期, 播放量, 推荐播放量, 分享播放量, 主页播放量, 朋友播放量, 订阅号消息播放量, 关注播放量, 其他播放量, 朋友量, 点赞量, 评论量, 分享量, 关注者量, 关注者总数
- **单篇**：发布日期, 封面, 作品时长, 播放量, 完播率, 平均播放时长, 朋友量, 点赞量, 评论量, 分享量, 关注量, 企微点击次数, 企微点击人数, 添加通讯录次数, 添加通讯录人数

### 抖音
- **汇总**：周期, 投稿量, 主页访问, 总播放量, 总点赞量, 总评论量, 总分享量, 5秒完播率, 2秒跳出率, 封面点击率, 平均播放时长(2位小数), 粉丝净增, 吸粉量, 脱粉量, 回访粉丝量, 总粉丝量
- **单篇**：作品标题, 发布日期, 封面, 作品时长, 播放量, 点赞量, 评论量, 分享量, 收藏量, 弹幕量, 完播率, 5秒完播率, 2秒跳出率, 平均播放时长, 涨粉量, 脱粉量, 粉丝播放占比, 最大流量来源, 搜索关键词

> **已知限制**
> - 抖音单篇来自列表接口 `work_list` 直取（秒出、不打开任何页面）。完播率 / 5秒完播率 / 2秒跳出率 / 平均播放时长 / 涨粉量 / 脱粉量 在抖音**汇总**中为整周期汇总（非单条）。
> - 【最大流量来源 / 搜索关键词】为每篇额外调用 `item/play/source`、`item_analysis/search/keyword` 获取；涨粉量对无涨粉作品为空。
> - 视频号单篇的 完播率 / 平均播放时长 来自 `post_list`，已包含在单篇 CSV 中。

## 错误提示

- **登录已失效**（请先登录对应平台）：
  - 视频号（`errCode` = 300333 / 300800 / 300334）：`登录已失效，请先登录「视频号」后再操作（若已登录请刷新页面重试）`
  - 抖音（`status_code` = 8）：`登录已失效，请先登录「抖音」后再操作（若已登录请刷新页面重试）`
- **其它接口错误**（错误码 + 原始信息）：
  - 视频号：`视频号数据获取失败！错误码{code}：{msg}`
  - 视频号单篇：`视频号单篇数据获取失败！错误码{code}：{msg}`
  - 抖音：`抖音数据获取失败！错误码{code}：{msg}`
- **请求失败**（网络 / 接口连接失败，重试 3 次后）：`请求失败：请确认已登录对应平台后再操作（若已登录请刷新页面重试）`
- 汇总成功但单篇失败时会提示可重试。
