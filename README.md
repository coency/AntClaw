# 爬爬蚁（AntClaw）

把自己账号的**创作者数据中心**数据一键导出为 **CSV**（含作品封面 ZIP）的 Chrome 扩展（Manifest V3），支持 **上一个月（自然月）** 与 **上一周（自然周）** 两种周期。

面向 **抖音创作者中心**（`creator.douyin.com`）与 **微信视频号助手**（`channels.weixin.qq.com`）；小红书、哔哩哔哩为占位（提示“暂未接入”）。

> **定位与免责**：只读工具。仅在你已登录的官方平台页面上、由你主动点击时，调用平台自身的数据接口读取统计；不绕过任何权限控制、不外发任何数据。请仅用于**本人账号**或**你被授权管理**的账号，并遵守对应平台的服务条款。

---

## 功能特性

- **两个平台**：抖音、微信视频号（同一弹窗内切换）。
- **两种周期**：上一个月（自然月）、上一周（自然周）。
- **三类导出**：
  - 汇总 CSV —— 周期内整体指标
  - 单篇 CSV —— 逐作品明细
  - 封面 ZIP —— 作品封面图打包
- **抖音单篇全接口直取**：标题 / 时长 / 播放 / 点赞 / 评论 / 分享 / 收藏 / 弹幕 / 完播率 / 5秒完播率 / 2秒跳出率 / 平均播放时长 / 涨粉 / 脱粉 / 粉丝播放占比 / 最大流量来源 / 搜索关键词，**秒出、无需逐个打开作品详情页**。
- **视频号企微指标**：单篇包含 企微链接点击次数 / 人数、添加通讯录次数 / 人数。
- **提取过程可离开**：提取期间可以关掉弹窗，完成后会有系统通知；重新打开弹窗会恢复上次结果，可直接下载。
- **温和的请求节奏**：同一平台两次提取至少间隔 60 秒（按平台独立计时）；列表翻页带间隔与上限，命中上限会明确提示而不是静默截断。

## 安装

### 从源码加载（开发者模式）

1. 获取源码：`git clone https://github.com/coency/chrome-extension-antclaw.git`（或下载仓库 ZIP 解压）。
2. 打开 `chrome://extensions`，右上角开启**开发者模式**。
3. 点「**加载已解压的扩展程序**」，选择**本仓库根目录**（即含 `manifest.json` 的那一层）。
4. 在已登录创作者平台的页面点击扩展图标即可使用。

> 仓库 ZIP 里还包含 `docs/`、`research/`、`README.md`，它们不是扩展运行所需文件；扩展本体就是根目录下的那些文件。

### 使用发布包

发布包命名为 `chrome-extension-antclaw-v<版本号>.zip`，解压后目录结构即为扩展本体（`manifest.json` 位于 zip 根目录），既可「加载已解压的扩展程序」，也可直接上传 Chrome Web Store。

## 使用方法

1. 先在浏览器登录对应平台：抖音 = `creator.douyin.com`，视频号 = `channels.weixin.qq.com`，并让该页面成为**当前标签页**。
2. 点击扩展图标，选择**平台**与**周期**。
3. 点「**提取数据**」。（提取期间可关闭弹窗，完成后会收到系统通知）
4. 提取完成后，点「**下载汇总**」「**下载单篇**」「**下载封面**」分别保存；每次下载都会弹出「另存为」对话框。

### 导出文件命名

| 内容 | 命名示例 |
|---|---|
| 汇总 CSV | `抖音_2026年08月_月度汇总数据统计.csv` |
| 单篇 CSV | `抖音_2026年08月_月度作品数据统计.csv` |
| 封面 ZIP | `抖音_2026年08月_月度作品封面.zip`，内部为 `01_<作品ID>.jpg`（视频号用发布时间戳） |

- CSV 为 **UTF-8（带 BOM）**，Excel 双击打开不乱码。
- 以 `=` `+` `-` `@` 开头、且**不是纯数字**的文本（标题、关键词等）会被加上前置 `'`，避免被 Excel/Sheets 当成公式执行；负数（如粉丝净增 `-3`）与百分比、科学计数不受影响。

## 权限说明

| 权限 | 用途 |
|---|---|
| `downloads` | 把 CSV / 封面 ZIP 保存到你选择的位置 |
| `storage` | 记录提取状态与上次结果，供弹窗恢复与下载（仅本机浏览器） |
| `unlimitedStorage` | 单篇明细较多时结果可能超过 `storage.local` 默认约 10MB 配额，避免写入失败丢失结果 |
| `notifications` | 提取完成后弹系统通知（弹窗已关闭时也能知道） |
| `host_permissions`：`creator.douyin.com`、`channels.weixin.qq.com` | 在你已登录的页面上调用平台自身接口，读取**你自己**的统计数据 |
| `host_permissions`：`*.douyinpic.com`、`finder.video.qq.com` | 下载作品封面图用于打包 ZIP |

**单一用途说明**：把你在抖音 / 视频号创作者后台可见的统计，导出成本地的 CSV 与封面 ZIP；不含任何其他功能，不做数据上传。

## 隐私与合规

- 本扩展**只读**、**本地运行**、**不采集 / 不上传任何数据**；无第三方服务器、无埋点遥测。
- 所有请求都由你的浏览器直接发往平台官方域名，凭证即你当前的登录态，扩展不存储、不转发。
- 仅用于**本人账号**或**你被授权管理**的账号。
- 详见隐私政策（`docs/index.html`）。

## 已知限制

- 抖音单篇来自列表接口 `work_list` 直取（秒出、不打开任何页面）。完播率 / 5秒完播率 / 2秒跳出率 / 平均播放时长 / 涨粉量 / 脱粉量 在抖音**汇总**中为整周期汇总（非单条）。
- 【最大流量来源 / 搜索关键词】为每篇额外调用 `item/play/source`、`item_analysis/search/keyword` 获取；涨粉量对无涨粉作品为空。
- 视频号单篇的 完播率 / 平均播放时长 来自 `post_list`，已包含在单篇 CSV 中。
- 为控制请求量，抖音作品列表最多翻 200 页（约 8000 条）、视频号单篇最多 50 页（约 5000 条）；一旦命中上限，会在结果提示里说明「仅导出前 N 条」，不会静默截断。抖音列表按时间倒序翻页，翻到所选周期起点之前即停止。
- 视频号的渠道来源分解依赖接口返回的渠道名；平台新增或改名时，未识别渠道会并入「其他」（总量不受影响）。
- 视频号接口依赖 Web 端固定参数（`_aid` 等）与页面内的账号标识；平台改版可能导致失败，需随版本更新维护。

## 常见问题（FAQ）

- **点「提取数据」提示先打开并登录平台？** 当前标签页不是所选平台。先打开并登录对应页面（抖音 `creator.douyin.com` / 视频号 `channels.weixin.qq.com`），再回弹窗点击。
- **提示「登录已失效」？** 刷新对应平台页面后重试。
- **下载按钮是灰的？** 需要先成功提取一次；或者该周期没有作品（单篇 / 封面不可下载）。
- **提取中关掉弹窗会丢数据吗？** 不会。结果已写入本地存储，完成后有系统通知；重新打开弹窗会恢复并可直接下载。
- **为什么不能连续点「提取数据」？** 同一平台有 60 秒冷却（按平台独立计时），用于降低对平台接口的压力；提取失败后是 5 秒短冷却。
- **封面 ZIP 里少了几张？** 封面链接有有效期，过期或域名不可达会失败；状态栏会显示失败张数与域名。
- **抖音某些列为空？** 涨粉量对无涨粉作品为空；「最大流量来源 / 搜索关键词」接口失败时会提示失败篇数。
- **换台电脑还能看到上次结果吗？** 不能，结果只保存在本机浏览器里。
- **扩展更新后原来的页面报错？** 内容脚本需要重新注入，扩展会尝试自动刷新该页一次；也可手动刷新。

## 错误提示

- **登录已失效**（请先登录对应平台）：
  - 视频号（`errCode` = 300333 / 300334）：`登录已失效（汇总接口错误码300333：{errMsg}），请先登录「视频号」后再操作（若已登录请刷新页面重试）`；单篇接口失败会标明「单篇接口错误码」。
  - 抖音（`status_code` = 8）：`登录已失效，请先登录「抖音」后再操作（若已登录请刷新页面重试）`
- **请求被平台拒绝**（视频号 `errCode` = 300800，`errMsg` 常见为 `request failed`）：`视频号汇总请求被平台拒绝（错误码300800：request failed）：请刷新页面后重试…`。**这不是登录问题**，通常是请求参数不被平台接受。排查线索：控制台 `[AntClaw]` 那行会打印失败的接口、错误码与本次请求区间。
  - 已知案例：统计区间必须对齐到自然日（`endTs` 取最后一天 `00:00:00`）。把 `endTs` 改成 `23:59:59` 会让区间变成「30 天 23:59:59」，平台直接返回 300800。
- **未找到视频号账号标识（finder id）**：`未找到视频号账号标识（finder id）：请确认当前浏览器已登录视频号助手，然后刷新该页面重试（F12 控制台会打印相关键名）`。这是**本地读取页面登录标识失败**，与接口登录态无关，先刷新页面；仍失败时把控制台 `[AntClaw]` 打印的键名发出来。
- **其它接口错误**（错误码 + 原始信息）：
  - 视频号：`视频号数据获取失败！错误码{code}：{msg}`
  - 视频号单篇：`视频号单篇数据获取失败！错误码{code}：{msg}`
  - 抖音：`抖音数据获取失败！错误码{code}：{msg}`
- **HTTP 错误**（不重试，直接提示）：`请求失败（HTTP {status}）：请确认已登录对应平台后再操作`
- **请求失败**（网络错误 / 超时 / 返回内容无法解析，重试 3 次后）：`请求失败：请确认已登录对应平台后再操作（若已登录请刷新页面重试）`。单次请求 20 秒超时。
- **部分成功会以 ⚠ 提示**（结果区第二行起），不会只给一半数据却不说话：
  - 汇总成功但单篇失败 → 提示可重试；
  - 汇总缺少 `totalData` 或字段格式异常 → 改用渠道分解求和，提示可能重复计数；
  - 粉丝 / 关注者数据为空 → 提示对应列为空；
  - 作品列表分页游标未推进 → 提示可能只抓取了部分作品；
  - 「最大流量来源 / 搜索关键词」有 N 篇失败、或部分明细接口提示登录失效；
  - 结果写入本地存储失败（如超配额）→ 提示尽快下载，因为关闭弹窗后可能无法恢复。

## 开发

无构建步骤、无第三方依赖，直接改源码即可；改完后到 `chrome://extensions` 点「**重新加载**」，再刷新平台页面。

### 代码结构

| 文件 | 职责 |
|---|---|
| `manifest.json` | MV3 清单：权限、host 权限、内容脚本注入范围、弹窗与后台声明 |
| `content.js` | 注入两个平台页面；读取页面登录态、调用平台接口、组装 CSV、回传结果 |
| `popup.html` / `popup.js` | 弹窗界面：平台/周期选择、提取触发、下载（CSV / 手写 ZIP）、冷却与状态提示 |
| `background.js` | Service Worker：提取完成后的系统通知 |

### 调用的平台接口

抖音（前缀 `https://creator.douyin.com/janus/douyin/creator/`）：

| 接口 | 用途 |
|---|---|
| `data/overview/dashboard` | 周期汇总指标 |
| `data/overview/dashboard/fans` | 粉丝指标（净增 / 吸粉 / 脱粉 / 回访 / 总粉丝量）|
| `pc/work_list` | 作品列表与单篇指标（时长、完播、互动等）|
| `data/item/play/source` | 单篇「最大流量来源」|
| `data/item_analysis/search/keyword` | 单篇「搜索关键词」|

视频号（前缀 `https://channels.weixin.qq.com`）：

| 接口 | 用途 |
|---|---|
| `POST /cgi-bin/mmfinderassistant-bin/statistic/new_post_total_data` | 周期汇总与渠道来源分解 |
| `POST /cgi-bin/mmfinderassistant-bin/statistic/fans_trend` | 关注者量 / 关注者总数 |
| `POST /micro/statistic/cgi-bin/mmfinderassistant-bin/statistic/post_list` | 单篇明细（含企微 4 个字段，必须走 `/micro/` 路径）|

### 维护提示

- 抖音的统计区间以请求体里的 `date_range` 为准；`recent_days` 仅为与前端请求形态保持一致，**不要**用它推导周期。
- 视频号的 `_aid`、`_rid`、`_pageUrl` 是 Web 端固定参数与随机串，平台改版时需同步更新。
- 视频号的统计区间**必须对齐到自然日**（`startTs` / `endTs` 都取 `00:00:00`），平台**按自然日含当天**统计：2026-09-30 真机对比确认，本扩展「上一个月」汇总`播放量`与视频号助手后台数字一致，末日数据没有丢失，`endTs` 保持 `00:00:00` 即可。
  - 反面案例：曾把 `endTs` 改成 `23:59:59`，区间变成「30 天 23:59:59」，平台直接返回 `300800 request failed`（这个错误码曾被误判为登录失效，现已拆分文案）。
  - 若将来再怀疑末日缺失，仍以「与后台数字对比」为准，**不要凭猜改区间**。
- 所有接口返回的数字 / 数组字段都做了类型保护：结构变化时会在结果里以 ⚠ 提示，而不是抛出 `a.reduce is not a function` 这类错误。
- 仓库目前不含自动化测试。纯逻辑改动（CSV 转义、日期区间、ZIP 打包）建议先在 Node 桩环境里验证，再上真机跑一次两个平台的提取。

### 打包发布

发布包只包含扩展本体，排除 `.git`、`docs/`、`research/`、`README.md`、`LICENSE`，且**文件位于 zip 根目录**（`manifest.json` 在根，可直接上传商店）：

```powershell
$v = (Get-Content manifest.json -Raw | ConvertFrom-Json).version
Compress-Archive -Path manifest.json,background.js,content.js,popup.html,popup.js,icon16.png,icon32.png,icon48.png,icon128.png `
  -DestinationPath "chrome-extension-antclaw-v$v.zip" -Force
```

- 命名规则：`chrome-extension-antclaw-v<版本号>.zip`。
- 作为 Chrome Web Store 的**更新**上传时，`manifest.json` 的 `version` 必须高于已发布版本。
