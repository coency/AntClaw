爬爬蚁（产品详情）

【一句话简介】
面向「抖音创作者中心」与「微信视频号助手」的创作者数据统计导出工具：一键把你自己账号的指定周期（上一个月 / 上一周）数据导出为 CSV 表格，并自动下载作品封面打包成 ZIP。只读、本地运行、不采集任何数据。

【它能做什么】
本扩展帮你把官方创作者平台「数据中心」页面展示的统计数字，按上一个自然月或上一自然周一键导成可打开的 CSV（适合用 Excel / 表格软件做分析、留存、复盘）：

【微信视频号】
- 汇总：播放量、各来源播放（推荐 / 分享 / 主页 / 朋友 / 订阅号消息 / 关注 / 其他）、朋友量、点赞量、评论量、分享量、关注量、关注者总数。
- 单篇：发布日期、封面、作品时长、播放量、完播率、平均播放时长、朋友量、点赞量、评论量、分享量、关注量、企微链接点击次数 / 人数、添加通讯录次数 / 人数。
- 作品封面自动下载并打包为 ZIP。

【抖音】
- 汇总：投稿量、主页访问、总播放量、总点赞量、总评论量、总分享量、5 秒完播率、2 秒跳出率、封面点击率、平均播放时长、粉丝净增、吸粉量、脱粉量、回访粉丝量、总粉丝量。
- 单篇：作品标题、发布日期、封面、作品时长、播放量、点赞量、评论量、分享量、收藏量、弹幕量、完播率、5 秒完播率、2 秒跳出率、平均播放时长、涨粉量、脱粉量、粉丝播放占比、最大流量来源、搜索关键词。
- 作品封面自动下载并打包为 ZIP。

说明：抖音单篇数据全部来自官方列表接口直取，秒出、无需逐个打开作品详情页。

【使用方法】
1. 在桌面版 Chrome 登录创作者平台：抖音 = creator.douyin.com；视频号 = channels.weixin.qq.com。
2. 点击扩展图标，选择平台、周期（上一个月 / 上一周）。
3. 点「提取数据」。
4. 提取完成后，可点「下载汇总」「下载单篇」「下载封面」分别保存 CSV 或封面 ZIP。

【为什么需要这些权限】
本扩展只在你已打开并登录官方平台的页面里、且在你点击按钮时才读取数据，全部在本机完成。

- 下载（downloads）：把导出的 CSV 和封面 ZIP 保存到你自己电脑。仅在你点击下载按钮时触发。
- 站点访问（host permissions）：
  - creator.douyin.com：读取抖音创作者中心统计。
  - channels.weixin.qq.com：读取微信视频号助手统计。
  - *.douyinpic.com、finder.video.qq.com：下载平台官方展示的封面图。
- 存储（storage）：在本机保存最近一次导出结果与状态，便于你在弹窗关闭后重新打开时仍可下载；数据只留在你的浏览器本地。
- 通知（notifications）：导出完成后弹一条本地通知，提示你数据已就绪（即使切到别的标签也看得到）；仅在导出完成时出现一次。

【隐私承诺】
本扩展不采集、不上传、不传输任何数据。它不连接任何第三方服务器，不做埋点 / 遥测 / 统计，也不读取账号密码或浏览记录。所有数据处理都在你的浏览器本地完成，结果只导出到你自己电脑。只在你主动点击按钮时、才读取你本人账号在官方页面展示的数据。详见隐私政策。

【适用范围】
- 仅适用于你本人、或你被授权管理的账号。
- 建议使用桌面版 Chrome + 官方桌面版创作者平台，以获得最佳效果。

【遇到问题】
- 若未登录对应平台，扩展会提示你先登录（提示「登录已失效，请先登录……」）。
- 若接口暂时不可用，会给出对应的错误码与原始信息。登录后刷新页面重试即可。
