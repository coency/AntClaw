# 爬爬蚁 · Chrome 应用商店上架材料汇总

本页汇总面向 Chrome Web Store 上架所需的全部材料（纯中文，符合最新上架规范）。

## 材料清单

1. 扩展本体（上传商店）—— creator-extractor_v1.1.2.zip，含 manifest / 图标 / 内容脚本 / 后台服务线程。
2. 产品详情（长描述）—— 产品详情-店铺描述.txt，商店 Overview 中文长描述。
3. 单一用途说明 —— 单一用途与权限说明.txt，一句话 + 展开说明。
4. 逐条权限理由 —— 单一用途与权限说明.txt，downloads / storage / notifications + 4 个主机权限。
5. 隐私政策页 —— docs/index.html（仓库 docs 目录，部署到 GitHub Pages 后填 URL）。
6. README —— README.md，开发 / 维护说明。

## 权限（与实际 manifest 一致）

声明权限（permissions）：downloads、storage、notifications

主机权限（host_permissions）：
- https://creator.douyin.com/*（抖音数据中心）
- https://channels.weixin.qq.com/*（视频号数据中心）
- https://*.douyinpic.com/*（抖音封面 CDN）
- https://finder.video.qq.com/*（视频号封面 CDN）

注：未声明任何未使用的权限（不含已移除的 scripting）。

## 上架流程

1. 把 docs/index.html 部署到 GitHub Pages，拿到隐私政策 URL。
2. 在 chrome://webstore/devconsole 完成开发者注册（含两重验证）。
3. 新建项目，上传 creator-extractor_v1.1.2.zip。
4. 填写：产品详情（见 产品详情-店铺描述.txt）、类别、权限用途说明（见 单一用途与权限说明.txt）、隐私政策 URL。
5. 先设为「不公开」进行自测，确认无误后改为「公开」。
6. 提交审核（通常几小时到几天）。

## 填表要点（供快速复制）

单一用途（一句话）：把你自己账号的抖音 / 微信视频号数据中心统计，按上一个月或上一周导出为 CSV（含作品封面 ZIP）。

权限用途（简版）：本扩展只在你已打开并登录的官方平台页面、且在你点击按钮时读取数据；downloads 用于保存 CSV 与封面，主机权限用于读取平台展示的数据与下载封面，storage 用于本机保存导出结果以恢复下载按钮，notifications 用于导出完成时的本地通知。不采集、不上传任何数据。

隐私承诺：不收集、不上传、不传输任何个人信息；本地只读；无第三方服务器、无埋点遥测。

## 提交时注意事项

- 审核可能就「调用官方平台内部数据接口」询问用途，请强调：只读、仅导出本人账号、与页面同源、低频、非自动化发布。
- 请把名称、图标、描述与扩展实际功能保持一致，避免夸大。
