单一用途与权限说明（Chrome Web Store 上架材料）

说明：本文档与实际 manifest.json 声明的权限逐一对应（downloads、storage、notifications + 4 个主机权限），不声明任何未使用的权限。

====================
一、单一用途（Single Purpose）
====================
本扩展的唯一用途是：帮助创作者把自己的账号在「抖音创作者中心」与「微信视频号助手」的数据中心统计，按上一个自然月 / 上一自然周导出为 CSV 文件，并下载作品封面打包为 ZIP。

它是一个本地、只读、由用户主动触发的导出工具：不修改平台内容、不发布任何内容、不采集或上传任何数据。

中文一句话：把你自己账号的抖音 / 视频号数据中心数据导出成 CSV 和封面 ZIP。

====================
二、逐条权限说明（与实际 manifest 一致）
====================

1) downloads（下载）
- 为什么：用于把导出的 CSV 结果文件和单篇作品封面（ZIP）保存到用户自己的电脑。这是导出工具的必需能力。
- 何时使用：仅在用户点击「提取数据」/「下载汇总」/「下载单篇」/「下载封面」时。安装时、后台、或自动场景不写入或下载任何文件。

2) storage（存储）
- 为什么：在本机保存最近一次导出结果及其状态（提取中 / 完成），这样当用户导出过程中或之后关掉 / 重开弹窗、或切换页面时，弹窗能恢复上次结果并重新启用下载按钮。
- 何时使用：仅在一次导出完成后，把用户自己的导出结果写入浏览器本地存储；数据不离开浏览器，仅本扩展可读。

3) notifications（通知）
- 为什么：导出完成时弹一条本地桌面通知，提示用户数据已就绪——即使用户中途切换标签页或关掉弹窗也能看到。
- 何时使用：仅在用户触发「提取数据」完成后弹一次。安装时、后台、或未经用户操作都不会推送。

4) 主机权限 https://creator.douyin.com/*（抖音）
- 为什么：从用户已打开并登录的抖音创作者中心页面，读取数据中心统计（总览、粉丝、作品列表），与页面自身请求同源。
- 何时使用：仅在用户打开 creator.douyin.com 并点击「提取数据」时。不访问其它站点。

5) 主机权限 https://channels.weixin.qq.com/*（视频号）
- 为什么：从用户已打开并登录的视频号助手页面，读取数据中心统计（汇总 / 粉丝趋势 / 单篇列表）。
- 何时使用：仅在用户打开 channels.weixin.qq.com 并点击「提取数据」时。

6) 主机权限 https://*.douyinpic.com/*（抖音封面 CDN）
- 为什么：下载单篇作品封面图（托管在官方抖音 CDN），以便打包成 ZIP 给用户。
- 何时使用：仅在用户点击「下载封面」时。安装时、后台、或自动场景不抓取封面。

7) 主机权限 https://finder.video.qq.com/*（视频号封面 CDN）
- 为什么：下载单篇作品封面图（托管在官方微信封面 CDN），以便打包成 ZIP。
- 何时使用：仅在用户点击「下载封面」时。

====================
三、数据使用 / 隐私
====================
- 不采集、不上传、不传输任何数据。所有处理均在用户浏览器本地完成，产物只保存到用户自己的电脑。
- 不执行远程代码。扩展仅向官方平台自身的数据接口发出与页面同源的只读请求，以读取平台原本就在界面展示给登录用户的指标。
- 无第三方服务器、无埋点、无遥测。详见隐私政策。

====================
四、说明给审核人员
====================
扩展调用的是抖音 / 微信官方创作者平台自身的网页数据接口（与网页本身调用的一致），读取当前登录账号的统计，供账号本人导出。它是只读的导出工具：不绕过访问控制、不修改数据、不自动发布、不进行批量循环或高频抓取。封面图仅来自官方 CDN，且仅在用户点击「下载封面」时获取。
